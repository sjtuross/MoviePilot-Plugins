# MoviePilot-Plugins

V3与V2分别提供同名插件，配置与用法相同。

## 神医媒体订阅请求插件

接收通过Emby Webhook发出的`library.subscribe`事件，参考官方「豆瓣想看」插件的订阅链路完成媒体识别、媒体库查重、可选搜索下载与订阅创建。

### 配置

- **前置要求**：MoviePilot设置中配置并启用了至少一个Emby媒体服务器
- **启用插件**：开启后才处理该Webhook事件
- **发送订阅处理通知**：新增订阅时复用MoviePilot原生带海报通知；媒体库已存在、订阅已存在或失败时补发带状态说明的通知
- **搜索下载**：开启后优先按系统订阅站点与订阅过滤规则组搜索过滤并下载（电影单次下载、剧集批量下载），无资源、下载失败或剧集不完整时自动补建订阅
- **重复事件忽略窗口**：同一部影片/剧集在窗口内重复收到时跳过，默认为300秒，设为0可关闭去重
- **清理历史记录**：开启并保存后立即清空插件历史记录并自动关闭开关

在Emby中启用神医的`媒体订阅请求`Webhook通知，请求内容类型设为`multipart/form-data`，并将地址指向：

```text
http://<地址>:3001/api/v1/webhook/?token=<API_TOKEN>
```

### 规则

- 使用`Item.ProviderIds.DiscoverItemType`判断电影/电视剧（缺失时再通过豆瓣详情兜底）；不使用`Item.Type`，因为探索频道条目的类型是`Trailer`
- 系统识别源为TMDB时：优先将`Item.ProviderIds.Douban`转换为TMDB身份并识别完整媒体信息（V3同时支持豆瓣续集剧集安全回退）→ 失败时回退使用Webhook自带的`Item.ProviderIds.Tmdb` → 最后回退豆瓣识别
- 识别成功后先调用媒体库查重，媒体库已完整存在时直接跳过订阅并记录为「媒体库已存在」
- 从`Item.Name`解析季号，兼容 `第二季`、`Season 2`、`S2` 等写法，解析不到时回退条目季字段
- 使用`exist_ok=True`创建订阅，并在插件详情页以海报卡片形式保留最近100条处理记录，支持单条删除与一键清理
